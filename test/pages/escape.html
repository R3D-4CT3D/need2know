Escape tests

Each variant tries to fingerprint you in a way that dodges simple API hooks. The extension should catch every one.

  • iframe: canvas fingerprint using a fresh about:blank iframe's untouched APIs, reached via contentWindow
  • frames: the same, but reached via window.frames[i]
  • srcdoc: the same, inside a srcdoc iframe after it loads
  • dom-fonts: font probing by measuring hidden <span> elements instead of a canvas
  • blob: a blob: iframe that runs its own fingerprinting script
  • data: a data: iframe that runs its own fingerprinting script
  • fingerprintjs: the real open-source FingerprintJS library
